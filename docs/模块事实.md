# 权限管理 模块事实

## 职责

权限点公共模块，负责权限点维护、角色权限绑定、权限列表和权限校验，并兼容 role 模块表。

## 数据表

- `permission_roles`
- `permission_permissions`
- `permission_role_permissions`

## API

- `GET /api/permission/hello`：模块探活
- `GET /api/permission/list`：查询权限点列表
- `POST /api/permission/create`：创建权限点
- `GET /api/permission/role-permissions`：查询角色权限绑定
- `PUT /api/permission/assign-permissions`：分配角色权限
- `POST /api/permission/check-permission`：校验角色权限
- `POST /api/permission/admin/ping`：后台连通性检查

## 实时事件

用户前端事件：

- 当前模块没有自有用户前端推送事件。

后台提醒事件：

- 当前模块没有自有后台实时提醒事件。

## 测试资产

- `tests/data.yaml` 声明本模块测试涉及的数据表、种子、清理和快照范围。
- 每个 `api-docs/endpoints/*.json` 里的 `endpoint_key` 都应有对应 `tests/*.test.json`。
- 新增、删除或修改接口时，必须同时更新 `api-docs/`、测试文件和必要的数据种子。
